Jeu Calque de Jeu Customisable (Layer 5)

Activez ce calque avec TG(5). Utilisez VIA / VIAL pour réassigner n'importe quelle touche pour n'importe quel jeu à la volée !

RGB Intelligent Dynamique : Notre scannage matriciel s'adapte en temps réel aux touches que vous configurez dans VIA :
* Les touches configurées comme inactives (KC_NO) s'éteignent automatiquement.
* Les touches de mouvement ZQSD restent animées d'une vague arc-en-ciel constante.
* Les autres touches de jeu actives s'illuminent en **Blanc**.
* La touche **Echap** s'illumine en **Violet**.

Fonctionnement Global & Système

Navigation entre les calques

Le clavier utilise des calques intelligents pour regrouper les touches par fonction :

  • Calques de Base : Calque 0 (Perso AY) et Calque 1 (AZERTY Base).
  • Raccourcis Système : Accessible en maintenant les touches de pouce pour ouvrir les Symboles (Layer 2) ou les Chiffres (Layer 3).
  • Calque Accents : Maintenez L2 + L3 pour activer les accents français.
  • Mode Jeu : Activez le calque de jeu (Layer 5) avec TG(5). Pour en sortir, appuyez sur la touche (main droite, sous le pouce) qui exécute TO(0).

Gestion de l'affichage OLED & RGB

Écran Principal (Gauche) :
* Ligne 1 : Mode actif (AY / AZERTY)
* Ligne 2 : Calque en cours
* Ligne 3 : Modificateurs actifs (Shift, Ctrl, Alt, GUI)
* Ligne 4 : **OS Détecté** (MacOS, Windows, Linux) qui alterne avec le menu **RGB** (échelle 0 à 9) lorsque le Calque LED est activé.

Écran Secondaire (Droit) :
* Affiche votre logo personnalisé : **ARKAN YOTA / CORNE KEYBOARD**.
